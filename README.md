# FOOD MAGIC

Food menu ordering website with cart and WhatsApp checkout (React + Vite).

## Run

```
npm install
npm run dev
```

Build for hosting: `npm run build` (output in `dist/`).

## Customise

- Menu items, prices, stock, banner and contact details: `src/data/menuData.js`
- WhatsApp number: `whatsappNumber` in `src/data/menuData.js`
- Photos: `public/images/` (replace a file with one of the same name)
